# Phase 0 Baseline Plan

*Status: complete (method). Contains no results; results are produced by running it.*

The dashboard's success metrics 1 and 2 (PRD section 4) cannot be made fully SMART because no baseline exists. This plan defines what to measure, how, and over what period, so targets can be set on evidence rather than guessed. Run it before claiming any efficiency or transparency improvement.

## Baseline A — current evaluation effort (unblocks success metric 1)

**What.** The time currently spent compiling one round of CALD service evaluation for reporting.

**How.**
1. Identify the next occasion CALD service evaluation is compiled (e.g. for an annual or quarterly report).
2. Log time spent on each step: gathering program data, gathering collection/staffing figures, locating the benchmark position, writing the summary, formatting for the audience.
3. Record total hours and the number of separate sources consulted.

**Output.** Baseline figure: "X hours and Y sources per evaluation round, as at [date]." Target then expressible as "reduce presentation/compilation time by Z% within the first full reporting cycle after launch."

**Note.** Measure presentation and compilation time only. The tool does not reduce data-collection effort, so collection time is recorded separately and excluded from the improvement claim.

## Baseline B — stakeholder access to performance information (unblocks success metric 2)

**What.** How stakeholders currently obtain a view of multicultural service performance.

**How.**
1. List the stakeholders who currently receive or request this information (management, Coordinator, Council, community partners).
2. Record how each currently gets it (bespoke report on request, not at all, etc.) and how often.

**Output.** Baseline: "current access is [e.g. on-request only, N times per year]." Post-launch measure: number of distinct stakeholders accessing the dashboard per quarter.
